# Панель управления сайтом «Тата Анастасия»

## 1. Обновите существующий GitHub-репозиторий

Обновите файлы репозитория `Kukuruza24110/tatakitchenguide` содержимым данного архива: `public/` и `functions/` должны лежать в корне. **Не создавайте новый проект Cloudflare.** Дождитесь нового успешного Production deployment.

Убедитесь, что параметры Cloudflare Pages остались: Framework None; Build command `exit 0`; Build output directory `public`; Root directory пустое.

## 2. Создайте хранилище KV

Cloudflare Dashboard → Storage & databases → KV → Create namespace. Название, например, `tata_site_storage`.

Cloudflare → Workers & Pages → проект `tatakitchenguide` → Settings → Bindings → Add → KV namespace.

Укажите **Variable name = `SITE_KV`** (точное написание обязательно), выберите созданное пространство `tata_site_storage`. Примените к Production. Создание ресурса KV и его привязка — два разных действия.

## 3. Установите пароль

В Cloudflare → Settings → Variables and Secrets → Add добавьте:

- Type **Secret**; Name **`ADMIN_PASSWORD`**; Value — сильный, уникальный пароль не короче 16 случайных символов, который храните только у себя.

Существующие `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` оставьте без изменений. Не отправляйте пароли или токены в чат и не загружайте их на GitHub.

**Сделайте новый деплой после добавления Binding и Secret** (например, новый Commit в GitHub). Для привязок это обязательно.

## 4. Вход и первая публикация каталога

Перейдите на `https://tatakitchenguide.pages.dev/admin/` и введите пароль администратора.

При первом запуске загрузятся четыре первоначальных гайда из `site-data.js`. Нажмите **Сохранить изменения** — каталог будет записан в KV. После этого редактируйте сайт через панель, не меняя `site-data.js`.

Обложка — первая фотография в списке изображений конкретного гайда. Остальные появляются на странице гайда.

## 5. Проверка

Откройте главную и страницу `/guides/guide.html?id=cream-cheese`, добавьте тестовое фото, смените цену и нажмите «Сохранить изменения». Убедитесь, что изменилось на сайте. Затем отправьте тестовую заявку и проверьте её в Telegram.

Для нового гайда используйте **Добавить гайд**, укажите название, цену, описание, изображения, сохраните и скопируйте постоянную ссылку. Удалённый гайд пропадает из каталога, и его ссылка показывает «Гайд не найден». Ранее существовавшие ссылки (`/guides/cream-cheese.html` и т.д.) перенаправляют на новые адреса.

## Ограничения и безопасность

- Фотографии: JPG/PNG/WebP/GIF, до 5 МБ каждая. Для favicon разрешён также ICO. Изображения хранятся в KV; удаление изображения из галереи только убирает ссылку, само изображение физически остаётся в KV до ручной очистки.
- KV работает с глобальной репликацией: изменения иногда появляются с небольшой задержкой.
- На бесплатном Cloudflare KV: 100 000 чтений, 1 000 записей в сутки и 1 ГБ хранения; на сайте каждый просмотр каталога и фотографии может создавать чтения KV. При большом трафике надо следить за лимитами.
- Для администратора используется cookie HttpOnly / Secure / SameSite=Strict, сессия на 8 часов. Установите уникальный длинный пароль, не используйте публичные компьютеры. Для усиления безопасности позже можно добавить Cloudflare Access / Turnstile.
- Админ-панель не принимает онлайн-оплату; «Купить» отправляет заявку в Telegram, как и раньше.
- Это KV-редактор для небольшой команды из одного администратора. Не редактируйте одновременно из нескольких вкладок: последнее сохранение перезаписывает предыдущее. Резервные копии каталога можно делать, выгружая содержимое KV.
