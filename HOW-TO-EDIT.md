# Как самостоятельно редактировать сайт

## Где менять данные

**Один файл:** `public/site-data.js`. В GitHub откройте его, нажмите значок карандаша и измените значения **внутри кавычек**. Не удаляйте запятые, фигурные и квадратные скобки. После правки выберите Commit changes. Cloudflare Pages опубликует новую версию автоматически.

- `success.title` — заголовок после успешной отправки.
- `success.message` — текст после отправки.
- `guides.cream-cheese`, `macarons`, `cakes`, `fillings` — четыре гайда.
- `title`, `price`, `kind`, `description` — название, цена, категория и описание.
- `contents` — пункты списка «Что внутри». Можно добавлять или удалять пункты (соблюдайте запятые).
- `images` — имена изображений. Первый файл — обложка и главное фото, остальные три — галерея.

## Как загрузить фото

Загрузите JPG/WebP в `public/images/` на GitHub. Имя в `images` должно точно совпадать с именем загруженного файла, включая регистр и расширение. Например `product-1.jpg`. Если изображения пока нет, останется старый плейсхолдер. Старайтесь сжимать изображения до 200–500 КБ, не загружайте фото гигантского размера.

## Что не нужно трогать

`functions/api/order.js` содержит серверный обработчик заявок для Telegram. `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` остаются в Cloudflare → Settings → Variables and Secrets. Они не должны появляться в GitHub.

## Публикация

Загрузите **содержимое архива** в корень существующего репозитория GitHub, сохранив папки `public` и `functions`. Примените commit. Cloudflare Pages подхватит изменения из `main`. Проверьте главную, четыре страницы и тестовую заявку после обновления. Не размещайте папку сайта целиком внутри другой папки.
