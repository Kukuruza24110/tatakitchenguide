# Тата Анастасия — сайт с админ-панелью

Обычный статический сайт Cloudflare Pages, дополненный Pages Functions и Workers KV.

**Панель:** `/admin/` — добавление/удаление гайдов, редактирование заголовков, цен, содержимого, изображений, favicon и текста подтверждения заявки.

**Покупательские страницы:** `/` и `/guides/guide.html?id=cream-cheese` (или другой постоянный ID).

**Telegram:** обработчик `/api/order` оставлен с прежним токеном в защищённых настройках Cloudflare.

Начните с `SETUP-ADMIN.md` — инструкция по публикации, KV binding `SITE_KV` и секрету `ADMIN_PASSWORD`.

`public/site-data.js` — стартовые данные только для первой инициализации. После первого сохранения каталог хранится в Cloudflare KV.
