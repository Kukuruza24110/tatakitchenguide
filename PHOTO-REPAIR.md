# Проверка фотографий

1. Замените файлы проекта в GitHub содержимым этого архива с сохранением папок `public` и `functions`. НЕ удаляйте существующее Cloudflare KV и его ключ `catalog`.
2. Дождитесь нового Production deployment. Настройки SITE_KV, ADMIN_PASSWORD и Telegram не изменяйте.
3. В админ-панели выберите НОВЫЙ файл JPG/WebP и нажмите «Сохранить все изменения». Старые записи, созданные с 9 байтами «undefined», непригодны и требуют повторной загрузки.
4. Откройте новый адрес `/media/<новый uuid>` из Network. Проверьте заголовки: content-type должен быть image/*, content-length — гораздо больше 9 (сравним с исходным файлом).
5. Через 60 секунд проверьте публичную главную страницу без кеша.

Изменено: проверка сигнатур файла при отдаче, Cache-Control no-store, новые адреса для предпросмотра, повторные попытки после кратковременной недоступности KV; добавлен локальный тест tests/photo.test.mjs.

Ограничение: Cloudflare KV является eventually consistent; изображения сразу после записи могут быть недоступны на отдельных узлах. Для большой фотогалереи предпочтительнее отдельное R2 хранилище. Этот патч исправляет обнаруженные ошибки в коде, но результат на вашем аккаунте должен быть подтверждён тестом после деплоя.
